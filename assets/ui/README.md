# Dreist UI graphics

Original artwork for Dreist, licensed like the rest of the workspace
(MIT OR Apache-2.0). Nothing here comes from the original plugin.

- `Fonts/Dreist-Icons.ttf`: the icon font. Same code points (U+E900..U+E92B)
  and meanings as the skins' icon captions; `dreist_gui::text` draws the
  skins' `FXpansion-Geist2-Icons` family with it.
- `Cursors/`: the named image cursors and their hotspots.
- `AppIcon.icns`, `AppIcon.png`: the app icon, a blue "D" on a dark rounded
  square (`scripts/icon.py`, the same style as Einst's); `scripts/build.sh`
  puts the `.icns` in `Dreist.app`.
- `Metronomes/`: synthesised click sets (`scripts/uigen/sounds.py`).
- `Skin/`: every panel layout (`.skin`), the stylesheets and the themes.
  Layouts come from `scripts/uigen/skins/` (one module per area); control
  names are what the editor binds to, everything else (geometry, captions,
  tooltips) is ours. Stylesheets come from `scripts/uigen/theme.py`.
- `preview.png`: contact sheet (not bundled).

Generated by `scripts/uigen/uigen.py` (needs skia-python and fontTools);
edit the drawing code there and rerun it, never the files here.
`python3 scripts/uigen/uigen.py --check` fails when they are stale.
