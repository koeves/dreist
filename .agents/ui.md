# UI: skins, styles, icons

Everything in `assets/dreist` (panel layouts `Skin/*.skin`, stylesheets and
themes, the icon font `Fonts/Dreist-Icons.ttf`, cursors, metronome clicks, the
app icon) is generated by `scripts/uigen/uigen.py`. Edit the generator, never
the generated files:

- `scripts/uigen/skins/`: panel layouts, one module per area (`pages.py`,
  `mixer.py`, `fx.py`, `dialogs.py`, ...). Control names are what the editor
  binds to; keep them when moving things.
- `scripts/uigen/theme.py`: stylesheets and the themes ("Dreist", "Ember").
- `scripts/uigen/sounds.py`: metronome sets.

Regenerate and check (needs python3 with `skia-python==144.1` and
`fonttools==4.68.0`, as CI pins):

    python3 scripts/uigen/uigen.py            # writes assets/dreist
    python3 scripts/uigen/uigen.py --check    # fails when assets/dreist is stale (CI runs this)

Never copy graphics or layouts from the original plugin into the generator
or `assets/dreist`.

## Looking at the result

    cargo run -p geist-gui --example skinshot -- [skin] [out.png] [theme] [scale]
    cargo run -p geist-gui --features window --example skinview -- [theme]
    cargo run -p geist-editor --example editorshot -- [project.geist] [out.png] [scale] [editor_tab] [utility_tab]

`editorshot` also takes `GEIST_MODAL=about|preferences|export|filefind|metadata`,
`GEIST_CLICK=Ctrl/Name`, `GEIST_MENU=...` and more (see the top of
`crates/geist-editor/examples/editorshot.rs`). UI changes usually move the
screen fingerprints: regenerate `crates/geist-editor/tests/golden/screens.txt`
(see building.md).
